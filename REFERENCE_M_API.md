# Приёмы движка: справочник M.*

Все функции ставят движение на общую таймлинию `M.tl` и сами добавляют звук (раздел «Звук»). Время `at` — секунды от начала ролика. Цель — селектор, элемент или список. Звук у любого приёма: `sfx: false` выключает, `sfx: 'имя'` заменяет.

## Сцены и переходы

`M.seq([['#s1', 0], ['#s2', 3.2, 'push-up'], ['#s3', 6, 'bars-left', {colors: ['#C8FF2E', '#fff']}]])` — когда какая сцена на экране и чем она входит. Время — момент смены (середина перехода).

| Переход | Что делает |
|---|---|
| `cut` | жёсткая склейка (по умолчанию) |
| `push-left/right/up/down` | новая сцена выталкивает старую |
| `slide-left/…` | новая наезжает, старая чуть уходит |
| `wipe-left/…` | новая открывается шторкой по маске |
| `iris` `{x, y}` | новая раскрывается кругом из точки (доли кадра) |
| `zoom` | пролёт сквозь: старая улетает на камеру, новая подлетает |
| `bars-left/…` `{colors, n}` | цветные полосы закрывают кадр и открывают новую сцену |
| `diag-left/right` `{colors}` | диагональные плашки проносятся через кадр |
| `circle` `{x, y, colors}` | цветной круг заливает кадр и растворяется |

Опции: `dur` (по умолчанию 0,65; у закрывающих 0,8), `ease`. Имя направления — куда едет: `push-left` и `diag-left` движутся справа налево. `M.scene(el, start, end)` — ручная видимость без переходов. Сценам без своего `z-index` он выставляется по порядку в списке.

Входящая сцена должна начать показывать содержимое к моменту смены: пустой кадр посреди перехода читается как дыра. Для прозрачных сцен поверх видео годятся `cut`, `push`, `slide`, `zoom` и закрывающие (`bars`, `diag`, `circle`); `wipe` и `iris` рассчитаны на сцены со своим фоном, иначе старый и новый текст лягут друг на друга.

## Текст

`M.text(цель, {at, in, by, stagger, dur, ease})` — вход текста по частям.
- `in`: `rise` (выезд из-под маски снизу, по умолчанию), `drop` (сверху), `fade`, `slide`, `pop` (упругий удар), `blur`, `flip`, `type` (печать, опции `cps`, `cursor: false`).
- `by`: `words` (по умолчанию), `chars`, `lines`.
- Несколько элементов в селекторе входят по очереди с шагом `gap` (0,12 с).
- Возвращает время, когда вход закончился.
- Умолчания: `dur` 0,6 с (у `pop` и `chars` 0,45), каскад 0,05 с по словам, 0,018 по буквам, 0,09 по строкам; печать 22 знака в секунду, курсор мигает ещё 0,8 с (`cursorHold`).
- Цель — элемент с простым текстом (`h1`, `p`, `div`, `span`). На flex-контейнер и на элемент со счётчиком `M.count` не ставь: для них `M.show`.

`M.textOut(цель, {at, out: rise|drop|fade|pop|blur, by, dur})` — выход.

`M.captions(M.data.words.clip, {into: '#cap', mode, max, hi, offset, from, to, upper, hold})` — субтитры по словам из распознанной речи.
- `mode: 'karaoke'` — группа слов стоит, произносимое слово подсвечивается цветом `hi`; `'pop'` — слова выскакивают по одному и остаются до конца группы.
- `max` — знаков в группе (16; одно слово на экран — `max: 1`). `offset` — сдвиг, если нарезка стоит не с нуля (`data-at − data-in`). `from`/`to` — взять только часть речи.
- Контейнер `into` — пустой блок, который ты сам поставил и оформил (шрифт, цвет). Плашка под строкой — стилем `.mo-capl { background: …; padding: .15em .5em; border-radius: .3em }`.

`M.count('#n', {to: 120, at, dur, from, suffix: '+', prefix, decimals})` — счётчик с тиканьем. В элементе сразу стоит итоговое число, поэтому акценты вокруг него (`burst`, `circle`) вызывай после `M.count`.

## Блоки целиком

`M.show(цель, {at, in: pop|rise|drop|slide|fade|wipe|grow|blur, stagger, dur})` — вход плашек, карточек, картинок, строк списка. `grow` растит от левого края (линии, полосы графика).
`M.hide(цель, {at, out: pop|rise|drop|slide|fade|wipe, dur})` — выход.

## Рисованные акценты (линия прорисовывается на глазах)

Цель — элемент, точка `[x, y]` или рамка `{x, y, w, h}`. Рамка элемента меряется в момент вызова, поэтому вёрстка к этому времени должна быть окончательной. Линия живёт в сцене своего элемента; точки и рамки — в сцене, которая на экране в момент `at` (другая — опцией `host: '#s2'`). Акцент вокруг окна с видео: `M.draw.brackets(w.shape('card'), {at})` — `w.shape(имя)` даёт рамку формы.

| Вызов | Результат |
|---|---|
| `M.draw.underline(el, {at, style})` | подчёркивание от руки; `style: 'wave'` — волна, `'scribble'` — штриховка |
| `M.draw.strike(el, {at})` | зачёркивание |
| `M.draw.circle(el, {at, pad})` | обводка овалом от руки |
| `M.draw.brackets(el, {at})` | уголки-рамка |
| `M.draw.highlight(el, {at, ink})` | маркер проезжает под словом; `ink` — цвет текста после |
| `M.draw.arrow(a, b, {at, bend, gap})` | изогнутая стрелка от `a` к `b` (элемент или точка `[x, y]`) |
| `M.draw.burst(el или [x, y], {at, n, pad, len})` | лучи-искры вокруг элемента или из точки (для точки `r1`, `r2`) |
| `M.draw.ring([x, y], {at, r2})` | расходящееся кольцо |
| `M.draw.confetti([x, y], {at, colors, n})` | хлопушка |
| `M.draw.path(d, {at, dur, width})` | любой свой SVG-путь |

Общие опции: `color` (по умолчанию `var(--accent)`), `width`, `dur` (0,45 с), `host`. `underline`, `strike`, `circle`, `arrow`, `path` возвращают объект с `.out(t)` — стереть линию. Точка `[x, y]`: пиксели, либо доли кадра, если оба числа ≤ 1.

## Иконки

`mo icons clock` ищет имя среди 5000 контурных иконок, `mo data <dir> --icons clock,rocket` кладёт их в проект. `M.icon('rocket', {into: '#slot', at, draw: 0.7, color, stroke})` рисует иконку штрих за штрихом внутри блока `#slot` (размер и цвет блока задаёшь вёрсткой). Иконка — обычный элемент: её можно двигать `tl`, качать `M.float`.

## Окно с видео пользователя

```html
<div class="win" id="win"><img data-footage="media/clip.mp4" data-in="0" data-at="0" data-audio data-voice></div>
```
```js
const w = M.win('#win', { face: M.data.faces['clip.mp4'], shape: 'full' });
w.to('card', 0.15);                       // форма меняется плавно, лицо остаётся в кадре с запасом над головой
w.to('circle', 4.2, { dur: 0.6 });
w.to('off-right', 7.0);                   // окно уезжает, графика занимает весь кадр
w.to('top', 9.0, { box: { h: 480, rot: -3 } });   // пресет с правкой размеров в px
```
Формы: `full`, `card`, `top`, `bottom`, `wide`, `circle`, `pill`, `left`, `right`, `pip-tl`, `pip-tr`, `pip-bl`, `pip-br`, `off-left/right/up/down`, либо свой объект `{x, y, w, h, r, rot}`. Пресеты считаются от безопасной зоны. Окно стоит вне сцен и между фоном и сценами по `z-index`; сцены поверх него прозрачные.

`mo faces media/clip.mp4` находит лицо, `mo data <dir> --faces clip.faces.json` кладёт его в проект. Если лицо не нашлось (профиль, очки, рисованный персонаж), посмотри лист кадров и задай рамку сам, в пикселях исходника, до вызова `M.win`: `M.data.faces['clip.mp4'] = {W: 1080, H: 1920, cx: 540, cy: 700, w: 280, h: 300}`. Без `face` окно кадрируется по `focusY` (20 % сверху), а проверка текста на лице не работает. Окно во весь кадр не качай `M.float`: оголятся края.

## Камера над большим холстом

```js
const cam = M.camera('#world');           // создай камеру до M.draw.* на этом холсте
cam.focus('#room1', null, { zoom: 1.2 }); // стартовое положение
cam.focus('#room2', 2.4, { zoom: 1, rot: -3 });   // перелёт к блоку; без zoom блок вписывается на 72 % кадра
cam.to({ zoom: 0.5 }, 6, { dur: 1.2 });   // отъезд на общий план
```
`#world` — блок больше кадра, сцены-«комнаты» расставлены по нему. Дети с `data-depth="0.6"` едут медленнее (параллакс). Перелёт по умолчанию 0,9 с с кривой `swift`. Камера центрирует по кадру, а не по безопасной зоне: в вертикали держи содержимое комнаты в её верхних двух третях.

## Жизнь, фактура, данные

- `M.float(цель, {x, y, rot, period})` — живое покачивание на удержании (окно, иконки, плашки; не мелкий текст). По умолчанию 8 и 12 px, период 4 с.
- `M.shake(цель, {at, amp, dur})` — встряска на акцент.
- `M.grain(0.12)` — плёночное зерно (накладывается при сборке файла, в стоп-кадрах его нет).
- `M.chart('#box', {type: 'bars'|'line'|'donut', data: [{label, value}], at, unit})`.
- `M.onFrame((t, frame) => …)` — canvas и всё процедурное как чистая функция от `t`; `M.rand(seed)` вместо `Math.random`; `M.box(el)` — рамка элемента в покое.

Кривые: все из GSAP (`expo.out`, `back.out(1.7)`, `power3.inOut`, `elastic.out(1, 0.5)`) плюс `swift` (резкий разгон и торможение — для перемещений), `glide` (длинное мягкое торможение), `punch` (вход с лёгким перелётом), `ant` (сначала чуть назад, потом вперёд). Своя кривая по замеру: `CustomEase.create('ref_03', 'M0,0 L0.083,0.202 …')` и `ease: 'ref_03'`.

## Звук

Приёмы озвучивают себя сами, слоями: движение получает подъезд, остановка — низкий удар, мелкое действие — деталь. Звук приходит чуть раньше картинки: подъезд ставится пиком на середину хода, удар — на момент остановки, нарастание — концом на удар. Эти якоря движок считает сам.

| Действие | Что звучит |
|---|---|
| переходы `push`, `slide`, `wipe`, `zoom`, шторки; смена формы окна | `whoosh` на ходу и `hit` в момент остановки |
| перелёт камеры | `sweep` и `hit` |
| строка текста (`rise`, `drop`, `slide`, `flip`), блоки (`show`) | тихий `swish` и `tap` на каждую строку или блок в момент остановки |
| `pop` текста и блоков | `pop` с подъёмом тона; для слова из трёх и больше частей в конце `hit` |
| печать | `key` на знак |
| счётчик | `tick` с ускорением и подъёмом, в конце `thock` и `chime` |
| линия, иконка | `scratch`, у иконки в конце `tick` |
| маркер | `swish` |
| лучи, конфетти | `pop` и `shimmer` |
| кольцо | `bubble` |
| встряска | `boom` |
| `iris`, круговая диаграмма, вход `blur` | `swell` |

Свои звуки и акценты:
- `M.hit(t, 'l')` — большой акцент: нарастание до `t`, большой удар с хвостом и звон. Один-два на ролик: хук и финал или главная цифра. `M.hit(t, 'm')` — подъезд и низкий удар. `M.hit(t, 's')` — щелчок с телом.
- `M.ticks(t, {n: 6, gap: 0.05, name: 'tick'})` — очередь щелчков с подъёмом (`rise: false` — ровная); `name: 'blip'` — трещотка.
- `M.sfx('boom', 2.4, {gain: -3, rate: 1.1, pan: -0.3, anchor: 'start'})` — любой звук в точке. `rate` меняет длину и высоту; `anchor`: `start`, `peak` или `end` — какая точка звука встаёт на время.

| Роль | Имена |
|---|---|
| удары, низ | `hit` (мягкий, с подъездом), `boom` (большой, хвост 1,5 с), `thud` (короткий), `stutter` (дроблёный бас 0,85 с — открывает ролик или большой переход) |
| движение | `swish` (0,25 с), `whoosh` (0,55 с), `sweep` (0,95 с), `riser` (нарастание 1 с с обрывом), `downer` (спад после удара) |
| детали | `thock`, `key`, `tap`, `tick`, `blip`, `pop`, `bubble`, `scratch`, `glitch`, `swipe` |
| тональные | `chime` (звон, хвост 1,4 с), `ping`, `swell` (мягкий подъём), `shimmer` (искры), `ding` |

Уровень задаёт роль: удары громкие, детали на 12–18 дБ тише. `gain` сдвигает от этого уровня. Низ идёт по центру, детали разложены по сторонам, на всё положен общий короткий «воздух». Два одинаковых звука в один кадр сливаются в один. `sfx: false` у приёма выключает его звук, `sfx: 'имя'` заменяет одним.

Записанные щелчки (`tap`, `key`, `swipe`) берутся из набора `data-sfx` на `#stage`: `01` мягкий, `02` тёплый и низкий (под голос бери его), `03` механический. Уровни движок ставит по замеру. С голосом: музыка на 17 LU ниже голоса с прибранной серединой, эффекты на 7 дБ ниже голоса, верх срезан, звонкие тональные тише ещё на 5 дБ; итог −14 LUFS. Без голоса и музыки динамика ударов сохраняется, уровень ставится по пику −1,5 дБ. Подстройка: `data-music-under="14"`, `data-sfx-gain="-3"` на `#stage`; `data-loudness="off"` — не приводить общую громкость (дорожка референса как есть). Для подложки из `mo music` темп и длину доли бери из её собственного вывода, а не из `mo beats`. Строка «Звук:» в выводе `mo render` — готовый отчёт: уровни и баланс полос «низ/тело/середина/верх».

## Разметка

- `#stage`: `data-width`, `data-height`, `data-fps`, `data-duration`, `data-safe` (`social`, `reels`, `tiktok`, `shorts`, `feed`, `broadcast`, `none` или `верх,право,низ,лево`), `data-loop`, `data-loudness`. Для горизонтального референса 16:9 бери `data-safe="broadcast"` или `none`, а не `social`.
- Нарезка: `<img data-footage>` с `data-in` (секунда исходника), `data-at` (секунда ролика), `data-dur`, `data-audio`, `data-voice` (это речь), `data-gain`, `data-oversize="1.2"` (запас резкости под увеличение).
- Музыка: `<audio src data-at data-in data-dur data-gain data-fade-in data-fade-out>`; `data-voice` — отдельная дорожка голоса; `data-duck` — приглушать под голос компрессором (только если в речи длинные паузы).
- Готовые классы (заняты движком, своим стилям давай другие имена): `.bg`, `.scene`, `.fill` (на весь кадр), `.safe` (колонка внутри безопасной зоны), `.win`, всё с приставкой `mo-`. `--u` — 1 % ширины кадра, `--safe-t/r/b/l` — отступы зоны.
- Метки для проверки: `data-decor` (декоративный текст), `data-small` (мелкая подпись), `data-bleed` (намеренно выходит за зону), `data-layer` (свой слой для рисованных акцентов, если блок двигается целиком), `data-cut="t1,t2"` (разрешённая жёсткая склейка элемента в эти моменты — только если она есть у референса).

## Грабли

- Адреса, ники и названия держи одной строкой: `white-space: nowrap`.
- Два `from()` на одно свойство одного элемента конфликтуют: для повторных движений `fromTo()` или `to()`.
- `repeat: -1`, CSS `transition`/`animation`, `setTimeout`, `<video>` при покадровой съёмке не работают: `mo check` их ловит.
- Если блок с рисованным акцентом потом уезжает целиком, дай блоку `data-layer` — линия поедет вместе с ним.
- Большие `blur()` и `backdrop-filter` замедляют рендер в разы.
- Эмодзи рисуются шрифтом Noto и как элемент дизайна не годятся: бери иконки.
- Кэш кадров нарезки лежит в `<dir>/.cache`; если видео в листе не обновилось, сотри его.
- `speed` меряет в кадре шириной 480 px: скорости двух роликов сравнимы только при одинаковом соотношении сторон.
- Самодельная функция «видим с a по b» (`tl.set(el,{autoAlpha:1},a); tl.set(el,{autoAlpha:0},b)`) — главный источник обрывов: она прячет элемент посреди его движения. Конец видимости ставь после того, как выход доиграл, или не прячь вовсе.
- Комментарий `//` перед кодом в той же строке выключает весь код после него (звук, твин). Комментарии — в конце строки или отдельной строкой.

# Ремесло: почему моушн выглядит дорого

Это не список запретов, а то, из чего складывается хороший ролик. Прочитай перед раскадровкой.

## Шесть вещей, которые отличают моушн-дизайн от анимированной презентации

1. **Иерархия движения, а не «одно действие».** В каждом ударе есть главное движение (титр, окно, цифра), два-три поддерживающих со сдвигом 2–4 кадра (подпись, линия, иконка) и фон, который живёт. Одинокая плашка на пустом кадре — презентация.
2. **Кривые с характером.** Вход: резкий старт и длинное торможение (`expo.out`, `glide`, 0,4–0,7 с). Выход вдвое короче и с разгоном (`power3.in`, 0,2–0,3 с). Перемещение: `swift`, 0,5–0,8 с. Упругий перелёт (`back.out`, `punch`) — на мелком и на акцентах. Рывок за 2–3 кадра и длинный доезд 8–12 кадров — самый «дорогой» вход. Линейно двигается только то, что должно выглядеть механизмом. Одна и та же кривая у всех элементов — признак шаблона.
3. **Внахлёст.** Ничто не стартует в один кадр: контейнер пошёл, через 2–4 кадра пошло содержимое, ещё через 3–5 дорисовался акцент. Выход прошлого и вход нового перекрываются на 4–8 кадров.
4. **Удержание живое.** Пока зритель читает, кадр не мёртвый: дорисовывается подчёркивание, тикает счётчик, покачивается окно (`M.float`), подсвечивается слово в субтитрах. Мёртвый кадр дольше 1,5 с в соцвидео — потерянный зритель.
5. **Связность.** Сцены не «слайды»: между ними проходит общий элемент (окно, цвет шторки, камера, линия). На ролик одна система переходов плюс один-два особых момента. Новый эффект на каждом стыке читается как любительство.
6. **Контраст масштаба и фактура.** Огромное слово рядом с мелкой подписью; слово, обрезанное краем кадра (`data-bleed`); асимметрия вместо «всё по центру». Сверху зерно (`M.grain`), а размытие движения финальный рендер добавляет сам.

## Ритм в числах (соцвидео 9:16, 10–60 с)

| Что | Ориентир |
|---|---|
| Первое движение | в первые 0,3 с; главная мысль читается к 1,0–1,5 с |
| Новое событие | каждые 0,8–1,5 с; пауза длиннее 2 с — только под важную фразу |
| Доля времени в движении | 45–70 % (меряет `mo analyze`) |
| Вспышка движения | 0,3–0,6 с; удержание 0,4–1,2 с |
| Время чтения | ≥ 1 с на 20 знаков после остановки текста |
| Кегль (кадр 1080) | главный титр 110–190 px, второй текст ≥ 56 px, подписи ≥ 44 px |
| Строка | до ~18 знаков крупным кеглем, 2–3 строки |
| Финал | стоит ≥ 1 с |

Под речь титр встаёт на первом слове фразы и уходит до следующей. Под музыку склейки и удары ставятся на доли (`mo beats`, `M.snap`). В режиме B ритм берётся из референса, а не из этой таблицы.

**Нижняя треть вертикального кадра.** Безопасная зона оставляет под текст примерно 15–65 % высоты: ниже лежит интерфейс площадки. Текст туда нельзя, а фон, окно с видео, крупную декоративную графику и обрезанные краем слова (`data-decor`, `data-bleed`) — можно и нужно, иначе весь ролик «висит наверху» над пустотой.

## Звуковой дизайн

Звук делает половину ощущения «дорого». Правила сняты замерами с роликов, где звук сделан хорошо; приёмы движка уже следуют им, твоя работа — расставить акценты и не замусорить.

1. **Три слоя на событие.** У заметного события есть движение (подъезд), удар (остановка) и деталь (щелчок, звон, шорох). Один звук на событие звучит плоско, пять — каша.
2. **Звук чуть раньше картинки.** Подъезд начинается до движения и достигает пика на середине хода, удар падает на остановку. Нарастание обрывается в ноль ровно перед ударом: короткая тишина делает удар сильнее.
3. **Иерархия.** Один-два больших удара на ролик (`M.hit(t, 'l')`): хук и финал или главная цифра. Средние удары — на сменах сцен, их ставят переходы. Всё остальное — детали, они на 12–18 дБ тише. Если большой удар стоит на каждой сцене, большого удара нет.
4. **Низ с телом.** Удары строятся на 40–100 Гц, но слышны и с телефона за счёт гармоник 150–600 Гц. Ориентир баланса в строке «Звук:» у ролика без голоса: низ 0, тело −3…−8, середина −6…−12, верх −12…−20 дБ. Перекос в середину и верх звучит как набор щелчков.
5. **Деталь повторяет действие.** Печать — щелчок на знак. Счётчик — тики, которые ускоряются и поднимаются, и звон на итоговом числе. Линия — шорох. Перечисление — очередь `pop` с подъёмом тона. Одинаковый звук на разные действия слышен как шаблон.
6. **Плотность.** В хороших роликах 4–5 звуковых событий в секунду, а пауза — осознанный приём. Тишина дольше секунды в середине ролика читается как дыра; в конце хвост большого удара может звучать один.
7. **Под голос.** Звонкие тональные (`chime`, `ping`, `shimmer`) не ставь на слова, только в паузы; движок сам делает их тише и срезает верх, но место выбираешь ты.
8. **Без музыки можно.** Ролик на одном звуковом дизайне — полноценный вариант. Музыку добавляй, когда пользователь дал трек или попросил её.
9. **Моно.** Пользователю звук сдаётся в моно: после рендера `ffmpeg -i out/final.mp4 -c:v copy -af "pan=mono|c0=0.5*c0+0.5*c1" -ac 1 -c:a aac -b:a 192k out/final_mono.mp4` и отдаёшь моно-файл. Панорама эффектов по сторонам в моно пропадает — это нормально.
10. **Главные точки — эпик.** По словам пользователя найди 1–3 кульминации («главный аргумент», «самое главное», «самая большая польза», вывод, CTA). На них самый мощный звук ролика (подъезд, который обрывается в тишину перед ударом, `boom` + `hit` + низкий спад) и самый мощный кадр (вспышка, удар, встряска, ударные волны). Остальные удары заметно слабее, иначе кульминации не слышно.
11. **Хук без дроблёных и «сломанных» звуков.** `stutter` и глитч на хуке — только по просьбе. По умолчанию хук открывает чистый удар с телом.
12. **Громкость не уплывает между версиями.** Правишь одно место — уровни остальных эффектов не трогаешь. Сравни строку «Звук:» новой версии с прошлой: если «громкий момент» стал тише больше чем на 1 дБ, а ты об этом не просил — верни. Жалоба «звуки стали тише» — брак.
13. **Звук печати — свой, с телом.** Щелчок на каждую букву, у каждого чуть другая высота и громкость, пробел звучит иначе, в начале куска низкий удар. Буквы и щелчки распределены по длительности того звука или слова, на котором печать.
14. **Правишь только то, что назвали.** Пользователь сказал «остальное оставь как есть» — меняешь только названный отрезок (по таймкодам) и проверяешь, что вне его кадры и звук совпадают с прошлой версией.

Открыть ролик можно дроблёным басом (`M.sfx('stutter', 0.02)`). Звук ты не слышишь: суди по строке «Звук:» и по `mo analyze`, а пользователю скажи, что тембр проверяет он.

## Восемь хуков (первые 1,5 секунды)

1. **Удар словом.** Огромное слово влетает по буквам (`pop`, `by: 'chars'`), лучи (`burst`), встряска. Через секунду сжимается и уступает место.
2. **Окно врывается.** Видео на весь кадр, на 0,1 с окно со стуком сжимается в карточку, рядом печатается титр.
3. **Зачеркнул и переписал.** Печатается утверждение, зачёркивается (`strike`), снизу выскакивает новое слово.
4. **Цифра.** Гигантский счётчик от нуля, под ним подпись выезжает из-под маски.
5. **Пролёт камеры.** Старт на крупной детали (zoom 2,5–3), камера отъезжает и открывает весь кадр.
6. **Шторка цветом.** Полосы акцентного цвета закрывают кадр и открывают первый титр.
7. **Маркер.** Строка выезжает, по ключевому слову проходит маркер (`highlight`), рядом рисуется стрелка.
8. **Вопрос и ответ.** Вопрос печатается с курсором, ответ выскакивает крупно другим цветом.

Для графики поверх видео хук начинается с лица на весь кадр: зритель должен увидеть человека, а уже потом графику.

## Графика поверх видео: что рисовать

Субтитры — фон, а не графика. Графика — это визуализация смысла: каждой фразе свой образ.

- Назвал число → счётчик или график. Перечислил → карточки появляются по одной на каждое слово.
- Назвал продукт, сайт, ник → плашка с названием одной строкой, уголки или подчёркивание.
- Сравнил → две колонки, зачёркивание, стрелка от одного к другому.
- Действие → иконка, которая рисуется, и стрелка к объекту.
- Эмоция или вывод → одно огромное слово на весь кадр, окно в это время уезжает.

Окно с человеком меняет форму от фразы к фразе и на части сцен покидает кадр, чтобы графика взяла его целиком: человек в кадре весь ролик — это просто видео с подписями. Текст и графика не закрывают лицо (`mo check` это меряет).

## Контраст выделений

Маркер, плашка или подсветка не должны сливаться с фоном: цвет выделения сравнивай с цветом под ним, разница яркости ≥ 40 % или другой тон. Акцентный цвет поверх фона того же акцента (лайм на лайме, жёлтый на жёлтом) — брак, бери тонкую линию, обводку или инверсию.

## Чего не делать без прямой просьбы

Фиолетово-голубые градиенты и «стекло», свечение вокруг всего, плывущие частицы, один и тот же «проявился и подъехал» на каждом элементе, шипящие «вжухи» без удара на переходах, один и тот же звук на все действия, наезды-удары камеры по лицу, глитч, один и тот же человек в двух окнах, эмодзи вместо иконок, выдуманные цифры, нарисованный по памяти чужой интерфейс, смена формата кадра относительно исходника, перемонтаж видео пользователя, свои переходы вместо переходов референса, выключенное размытие движения. Причина одна: так выглядит каждый второй сгенерированный ролик, и зритель считывает это за секунду.
