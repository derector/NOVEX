# Motion Director: как я делаю видео от А до Я

Важно: файлов MASTERSKILL.md и ANGSKILL.md в загрузках нет (папка uploads пустая). Всё ниже взято из двух установленных скиллов: `motion-director` (правила и приёмы) и `motion-engine` (код движка). Если нужно учесть твои файлы, загрузи их ещё раз.

## 1. Принцип

Результат не промт, а готовый MP4. Я пишу страницу `index.html`, движок снимает её кадр за кадром в браузере без окна, FFmpeg собирает MP4 и сводит звук.

Хорошо получается: титры и кинетика, субтитры по словам, плашки, цифры и графики, схемы, иконки, рисованные акценты, окно с видео, меняющее форму.
Не получается: персонажи, органика, фотореализм, 3D (это работа видеомоделей).

Главные правила движка:
- Кадр зависит только от времени `t`. CSS transition, setTimeout, requestAnimationFrame, Math.random и тег video запрещены. Всё движение это приёмы `M.*`, твины в `M.tl` или функции от `t` в `M.onFrame`.
- Собираю из готовых приёмов, а не из голых твинов. Вёрстка потоком (flex, grid, `.safe`), а не абсолютными координатами.

## 2. Пакеты и зависимости

| Что | Зачем |
|---|---|
| Node.js | `mo.cjs`, `asr.cjs`, `facecut.cjs`, `jumps.cjs` |
| Браузер без окна (headless Chromium через движок) | покадровая съёмка страницы |
| FFmpeg / ffprobe | сборка MP4, звук, декодирование, замеры |
| GSAP + CustomEase (лежат в каркасе `lib/`) | анимация и кривые из замеров |
| `sts-whisper-small`, `@huggingface/transformers@3` (npm, около 1 ГБ) | распознавание речи, слова с таймкодами |
| Python: `numpy`, `opencv-python-headless` | `speed.py`, `pops.py`, `faces.py` (лица, оптический поток) |
| `onnxruntime` + модель `u2net_human_seg.onnx` | маска человека для титров за головой |

Установка: движок выгружается из скилла в `~/.cache/motion-director/tool/`, проверяется хэшами и `mo doctor --selftest` (нужно «7 файлов, движок v3» и «САМОТЕСТ: пройден»).
Речь ставится отдельно, один раз, только если в материале есть голос:
`npm i sts-whisper-small @huggingface/transformers@3`

## 3. Три режима

| Прислали | Режим |
|---|---|
| своё видео (говорящая голова) | A: графика поверх видео |
| чужой ролик и «сделай так же» | B: копия референса «один в один» |
| только идея или текст | C: ролик с нуля |

Своё видео плюс референс это B поверх A: всё оформление берётся из референса, из видео пользователя только речь и смысл.

## 4. Железные правила (коротко)

1. **Слова пользователя главнее всего.** «Точно такие же», «один в один», «скопируй» значит копия один в один по всему ролику. Перед сборкой выписываю его требования в `ref_an/requirements.md` и проверяю каждое.
2. **Исходник не трогаю.** Длина и монтаж видео пользователя сохраняются кадр в кадр. Не режу паузы, не меняю порядок, не кадрирую.
3. **Формат и fps как у исходника или референса.** Ориентацию не меняю по своей воле.
4. **Голова целая.** От макушки до подбородка, запас не меньше 6 % высоты головы. Проверка `facecut` кадр за кадром. Срез значит брак.
5. **Плавность.** Ничего не обрывается и не дёргается. Своих переходов не изобретаю, только из референса или из приёмов движка. Размытие движения (`--mblur 4`) не выключаю.
6. **Самопроверка.** Каждый критерий не ниже 7, среднее не ниже 8, иначе не отправляю. Отговорки вроде «замер ненадёжный» запрещены, чиню замер.
7. **Время.** Ролик 20–30 с около 40 минут до черновика. Итерации отрезками `--draft`, полный рендер один раз после всех автопроверок, не больше двух рецензий.

## 5. Пайплайн по шагам

**Шаг 0. Вопросы** (до разбора и рендера): 2–4 вопроса кнопками, рекомендованный вариант первым. A: что делаем, звук, субтитры, что обязательно на экране. B: уровень копии (не задаётся, если есть слова «один в один»), звук, содержание, откуда картинки. C: формат, длина, звук, текст.

**Шаг 1. Разбор входа (молча)**
1. Память и прошлые чаты: не повторять то, что пользователь браковал.
2. `mo probe файлы --sheet`: размер, fps, длина, звук, HDR, лист кадров.
3. `asr файл --lang ru --json x_words.json --srt x.srt`, затем правлю расшифровку по смыслу (имена, термины), таймкоды не трогаю.
4. `mo faces видео`: трек лица `[t,x,y,w,h]` каждые 0,2 с, кладу в проект целиком.
5. `mo beats` для музыки. `mo analyze` для референса.
6. Озвученные пользователем эффекты («пиу», «вжух»): `onsets.py`, метки «вне слов». Звук значит когда, подводка значит что. Три звука после «три линии» это ровно три линии.
7. Референс в 24 к/с залит в 30: чистая копия `ffmpeg -vf "scale=540:-2,decimate=cycle=5,setpts=N/24/TB,framerate=fps=30"`.

**Шаг 2. Сценарий ударов:** таблица `время · мысль · что на экране · приём · форма окна` (в B ещё ход в кадрах и кривая). Удары стоят на фразах из asr. У каждого удара образ: цифра это счётчик, перечисление это карточки, название это плашка с подчёркиванием, действие это иконка со стрелкой, вывод это огромное слово. Если больше трети ударов просто «текст на плашке», сценарий слабый. Первая секунда хук, последняя стоящий кадр.

**Шаг 3. Три направления стиля** (в B «один в один» пропускается): тестовые доски `mo sheet --at … --title A --out board_A.jpg`, выбор по доске.

**Шаг 4. Сборка:** `mo init dir --size WxH --fps N --dur S`, `mo fonts` (только шрифты с кириллицей), `mo data` (иконки, слова, лицо в `M.data.*`), затем `index.html` из приёмов `M.*`.

**Шаг 5. Проверка:**
`mo check` → `facecut.cjs` → `jumps.cjs` → `pops.py` → (B) `speed --vs` и `mo compare` → одна рецензия свежим подагентом.

| Критерий | Порог |
|---|---|
| Формат, требования, исходник | совпадает, иначе 0 |
| Плавность (B: speed --vs) | среднее ≥ 8, худшее ≥ 7 |
| Ритм (B: mo compare) | сходство ≥ 0,8 |
| Композиция и цвет | палитра < 15 |
| Текст (`mo check`) | всё читается |
| Звук | 4–5 событий/с, 1–2 больших удара |
| Обрывы (`jumps`, `pops`) | не больше референса + 0,1 моментов/с |
| Свои переходы | ни одного придуманного |
| Свежий взгляд | ≥ 8 |

**Шаг 6. Черновик и финал:** черновик пользователю в полном размере и с размытием (`mo render dir --out out/draft_full.mp4`), с таблицей оценок и цифрами звука. Финал только после одобрения. H.264, звук AAC, −14 LUFS.

## 6. Режим A: каркас

```html
<div id="stage" data-width="1080" data-height="1920" data-fps="30" data-duration="15" data-safe="social" data-sfx="02">
  <div class="bg" data-bg></div>
  <div class="win" id="win"><img data-footage="media/clip.mp4" data-in="0" data-at="0" data-audio data-voice></div>
  <section class="scene" id="s1"> … </section>
  <section class="scene" id="s2"> … </section>
  <div id="cap"></div>
</div>
<script>
M.start(({ tl }) => {
  const w = M.win('#win', { face: M.data.faces['clip.mp4'], shape: 'full' });
  M.seq([['#s1', 0], ['#s2', 3.4]]);
  M.captions(M.data.words.clip, { into: '#cap', mode: 'karaoke' });
  w.to('card', 0.12);
  M.text('#s1 h1', { at: 0.3, in: 'pop', by: 'chars' });
  M.draw.burst('#s1 h1', { at: 0.8 });
  w.to('off-right', 3.2);
});
</script>
```

Ролик начинается с человека на весь кадр, до 0,3 с окно меняет форму, на части сцен уходит из кадра. Лицо при любой форме целое (`face` в `M.win`). Субтитры это фон, на плашке.

## 7. Режим B: копия референса (как я мерю и переношу)

1. `mo analyze`, `mo strip`, `mo grab --grid` на каждую сцену.
2. Файлы: `ref_an/requirements.md`, `ref_an/passport.md`, `ref_an/scenes.md` (время, тип, позиции в долях кадра, шрифт и кегль, вход и выход, картинка).
3. Фото-вставки: нахожу в интернете такие же или похожие, скачиваю, смотрю. Не нашлось, останавливаюсь и прошу тебя прислать или даю промты для генерации. Заменить плоской карточкой нельзя.
4. Каждое движение меряю: `speed ref.mp4 --from a --to b --out spd/ref_NN` даёт старт, ход в кадрах, пик скорости, ближайшую кривую и готовый `CustomEase`. В код идёт длительность из замера и `CustomEase.create("ref_NN", "…")`, не `power3.inOut` на глаз.
5. Сверка: `speed мой.mp4 … --vs spd/ref_NN.json`, оценка из 10.
6. Привязка к человеку: рамки и подписи за головой через `faceAt(t)` (гаусс 0,25 с, для перекадровки видео 0,5–0,7 с). Титр за головой: маска `u2net_human_seg.onnx`, слой «человек на белом», `mix-blend-mode:darken`.
7. Звук: свой звуковой дизайн без музыки, удары на тех же действиях, что у референса.

## 8. Звук

Движок сводит голос, музыку, звуковые эффекты. Музыка под голос приглушается автоматически (`data-music-under="23"` если голос тонет). Служебная подложка: `mo music out.wav --mood drive|chill|pulse|calm --dur 15`. Итоговая громкость −14 LUFS, отчёт «Звук:» с балансом полос.
